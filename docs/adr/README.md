# Architecture Decision Records

Use this directory for decisions that materially affect architecture, dependencies, content modeling, deployment, analytics, AI, animation, or design system direction.

## Format

```md
# 0001 Decision Title

## Status

Proposed | Accepted | Superseded

## Context

What problem are we solving?

## Decision

What did we choose?

## Alternatives Considered

What else did we evaluate?

## Tradeoffs

What gets better and what gets harder?

## Rollback

How would we unwind this decision if it stops serving the project?
```
